# React + Express Application

This project has two folders:
- `frontend` (React)
- `backend` (Express)

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Shahryar-Sohail/Access-Simulator.git
cd Access-Simulator
```
### 2. Setup Backend (Express)
```bash
cd backend
npm install
npm run dev
Backend will run on http://localhost:3000
```
### 3. Setup Frontend (React)
```bash
cd frontend
npm install
npm run dev
Frontend will run on http://localhost:5173
```
